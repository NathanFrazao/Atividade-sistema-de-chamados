# Aula 01 — arquitetura final

```text
USUÁRIO
↓
FRONT-END / SPA
↓
HTTP / JSON
↓
BACK-END / API
↓
BANCO DE DADOS
```

## Usuário
Pessoa que utiliza o sistema.

## Front-end
Interface:
- formulários;
- tabelas;
- botões;
- mensagens.

## SPA
Single Page Application.

A página-base permanece carregada e o JavaScript atualiza a interface.

## HTTP
Protocolo usado na comunicação Web.

## JSON
Formato textual para troca de dados.

## Back-end
Parte executada no servidor.

## API
Interface de comunicação entre front-end e back-end.

## Banco
Mantém dados persistentes.
